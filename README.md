# Smart City Traffic AI

A clean monorepo for the Smart City Traffic AI project.

## Project Structure

- `backend/`: Backend services and API.
- `frontend/`: Web application and user interface.
- `ai-engine/`: AI and machine learning models for traffic prediction and control.
- `sumo/`: Simulation of Urban MObility (SUMO) integration and configurations.
- `database/`: Database schemas, migrations, and scripts.
- `docker/`: Dockerfiles and docker-compose configurations.
- `docs/`: Project documentation.
- `scripts/`: Utility and automation scripts.
- `models/`: Trained model weights and checkpoints.
- `datasets/`: Data used for training and simulation.
